# Deckly

A simple, tidy, and comfortable taskboard in your Chrome side panel.

## Installation

Follow these steps to install **Deckly** manually in Google Chrome:

1. **Download the repository**
   * Click the green **`<> Code`** button at the top of this repository page.
   * Select **Download ZIP**.
   *(Masukkan screenshot download ZIP dari repository kamu di sini)*

2. **Extract the ZIP file**
   * Locate the downloaded `Deckly-main.zip` (or `Deckly.zip`) file on your computer.
   * Right-click the file and select **Extract All...** (or unzip it using your preferred archive tool).

3. **Open Chrome Extensions**
   * Open Google Chrome and navigate to `chrome://extensions/` in the address bar.
   * Enable **Developer mode** using the toggle switch in the top-right corner.

4. **Load the extension**
   * Click the **Load unpacked** button in the top-left corner (seperti yang ditandai dengan kotak merah pada gambar di bawah).
   * Browse and select the extracted **`Deckly`** folder (make sure to select the folder containing `manifest.json`).

   ![Load Unpacked](assets/Load%20unpacked%20image.jpeg)
   *(Masukkan gambar yang sudah diedit dengan kotak merah di atas. Jangan lupa ganti "path_ke_gambar_kamu/image_10.png" dengan lokasi folder penyimpanan gambarmu di GitHub, atau drag-and-drop langsung gambarnya saat mengedit di GitHub)*

Once loaded, **Deckly** will appear in your extensions list and is ready to use from your Chrome side panel!
